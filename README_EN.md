## 🌟 Introduction

WritingStudio is not a toy tool that "generates a paragraph with one click". It's a local AI writing studio built for long-form Chinese novel creation. It also supports social media articles, topic inspiration, and content rewriting.

Core philosophy: **Transform uncontrollable inspirational writing into a decomposable, progressive, and accumulative creative project.**

> ⚠️ This repository only provides publicly distributed installers and documentation. **Source code is not included.**

---

## ✨ Features

### 📚 Novel Writing

| Module | Description |
| :--- | :--- |
| **Project Management** | Create/manage multiple novel projects; organize by volumes and chapters; quick switching via sidebar; distinguish draft and final status; continue existing projects |
| **Outline Generation** | Generate full-book outline from story ideas; support outline continuation; progressive volume/chapter breakdown; establish main plot, phase goals, and story direction |
| **Chapter Writing** | Generate body text from chapter outline; natural continuation; temporary writing style control via extra instructions; preview context to reduce disconnection; pre-generation checks |
| **Chapter Summaries** | Auto-generate summaries for each chapter; use as context for subsequent chapters; avoid "starting from scratch" in long-form writing |
| **Character Management** | Manage character info; extract key characters from text; track character experiences and changes; maintain consistency |
| **AI Polish & Finalize** | AI polishing for body text; chapter finalization; auto-update summaries, character profiles, and memory after finalization |
| **Hook & Engagement** | Generate chapter hooks; create suspense, cliffhangers, and engagement points; designed for serialized web novels |
| **Quality Check** | Detect AI-style text; check character/plotline/task continuity; identify inconsistencies |

### 📰 Social Media & Inspiration

| Module | Description |
| :--- | :--- |
| **Social Media Writing** | Original article generation; imitation/rewrite; topic inspiration; configurable article type, field, word count, tone, and target platform |
| **Web Novel Inspiration** | Web novel direction assistance; idea generation; for when you're stuck or need plot points/settings |

## 📥 Download & Install

### Download from Releases

Please visit the [Releases page](https://github.com/lingxiaoyiyu-hub/WritingStudio/releases) to download the latest version:

- `WritingStudio_v3.5.0.zip` — Current release package

### Installation Steps

1. Download `WritingStudio_v3.5.0.zip`
2. Extract to any local folder
3. Double-click to launch
4. Configure your model API in **Model Settings** (supports OpenAI-compatible protocols)
5. Return to home, select **AI Creative Writing** or **Social Media Writing** to start

> 💡 **First-time tip**: Verify your API Key and model name in settings before starting serious writing.

---

## 🚀 Quick Start

1. **Launch**: Double-click WritingStudio
2. **Configure Model**: Enter API Key and model name in settings
3. **Create Project**: Click "New Novel Project", enter story ideas and settings
4. **Generate Outline**: Use outline generation to create the full-book structure
5. **Start Writing**: Enter chapters, generate body text, and refine

For detailed usage, see the [Usage Guide](docs/usage.md) (Chinese).

## 📖 Recommended Novel Writing Workflow

```
Create new novel project
    │
    ▼
Enter story ideas and basic settings
    │
    ▼
Generate full-book outline ────────► (Optional) Continue outline
    │
    ▼
Split into volumes and chapters
    │
    ▼
Enter chapter, supplement chapter outline
    │
    ▼
Generate body draft
    │
    ▼
AI Polish / Hooks / Quality Check — iterate
    │
    ▼
Confirm and finalize ────────► Auto-update summary, character profile, memory
    │
    ▼
Continue to next chapter
```
