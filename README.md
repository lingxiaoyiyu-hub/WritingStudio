# WritingStudio 3.3.0

WritingStudio 是一款面向中文小说创作的本地 AI 写作工作台，也支持自媒体文章、选题灵感和内容改写。

它的重点不是简单生成一段文字，而是把长篇小说写作拆成更稳定的流程：先做全书大纲，再拆卷、拆章、写正文、定稿、沉淀角色和上下文，尽量让后续章节能接得住前文。

本仓库只提供公开发行版下载，不包含源码。

## 核心功能

### 小说项目管理

- 创建和管理小说项目
- 按卷、章节组织长篇内容
- 左侧章节列表快速切换章节
- 草稿和定稿状态区分
- 支持继续写作已有项目

### 大纲推演

- 根据故事灵感生成全书大纲
- 支持续写大纲
- 支持分卷、分章推进
- 帮助作者先搭好主线、阶段目标和剧情走向

### 章节正文创作

- 根据本章大纲生成正文
- 支持按章自然续写
- 支持额外指令，临时控制本章写法
- 支持预览上下文，减少前后文断裂
- 支持生成前检查，提醒大纲、摘要、定稿等资料是否完整

### 章节摘要与上下文

- 每章可以生成章节摘要
- 摘要会作为后续章节的上下文参考
- 适合长篇小说持续创作，避免每一章都从零开始

### 角色管理

- 管理小说角色信息
- 从正文中提取关键人物
- 记录角色在章节中的经历和变化
- 后续写作时可作为人物一致性的参考

### AI 润色与定稿

- 对正文进行 AI 润色
- 支持章节定稿
- 定稿后可更新摘要、角色履历和记忆信息
- 更适合“先生成初稿，再反复打磨”的写作方式

### 钩子与爽点辅助

- 支持生成章节钩子
- 用于制造悬念、断章点和追读点
- 适合网文连载场景

### 质检工具

- 检查正文中的 AI 味
- 检查人物、线索和任务是否断档
- 支持连续性分析
- 帮助发现前后文不连贯的问题

### 文网与灵感

- 提供网文方向的创作辅助
- 支持灵感生成
- 适合卡文、缺剧情点、缺设定时使用

### 自媒体写作

- 支持原创文章生成
- 支持模仿二创
- 支持选题灵感
- 可设置文章类型、内容领域、目标字数、语气风格和目标平台

## 使用方法

1. 下载 `WritingStudio3.3.0.zip`
2. 解压到本地文件夹
3. 双击启动程序
4. 在模型配置里填入自己的模型接口
5. 回到首页，选择 AI 创意写作或自媒体写作

## 推荐小说写作流程

1. 新建小说项目
2. 输入故事灵感和基础设定
3. 先生成全书大纲
4. 拆分卷和章节
5. 进入章节，补充本章大纲
6. 生成正文初稿
7. 用 AI 润色、钩子、质检继续打磨
8. 确认后点击定稿
9. 继续写下一章
