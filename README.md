# WritingStudio 3.3.0

WritingStudio 是一款本地运行的 AI 写作辅助工具，适合小说创作、自媒体写作、章节规划、角色设定和长文润色等场景。

本仓库只提供软件发行版下载，不包含源码。

## 下载

请在右侧 **Releases** 中下载最新版：

- `WritingStudio3.3.0.zip`

下载后解压，运行程序即可。

## 主要功能

- AI 创意写作
- 自媒体文章生成
- 大纲推演

- 角色与世界观管理

## 使用说明

1. 下载 `WritingStudio3.3.0.zip`
2. 解压到本地文件夹
3. 双击启动程序
4. 根据界面提示配置模型后使用
