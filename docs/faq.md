## 基础问题

### Q: WritingStudio 是什么？

WritingStudio 是一款面向中文长篇小说创作的本地 AI 写作工作台。它把长篇写作拆成可拆解、可推进、可沉淀的流程，支持大纲推演、章节续写、角色管理、质检润色等功能，也支持自媒体文章创作。

### Q: 支持哪些操作系统？

支持 Windows、macOS 和 Linux 三大主流桌面平台。

### Q: 软件是免费的吗？

是的，WritingStudio 公开发行版可以免费使用。你需要自行准备 AI 模型的 API Key。

### Q: 为什么不提供源码？

项目目前处于闭源状态，但我们欢迎通过 Issue 反馈问题和建议，也接受文档类的 Pull Request。

## 模型配置

### Q: 支持哪些 AI 模型？

支持所有 OpenAI 兼容协议的模型，包括但不限于：

- **OpenAI**：GPT-3.5、GPT-4、GPT-4o 等
- **DeepSeek**：deepseek-chat、deepseek-coder 等
- **智谱 AI**：GLM-4、GLM-3 等
- **通义千问**：qwen-turbo、qwen-plus 等
- **月之暗面**：Kimi 系列
- 其他兼容 OpenAI API 格式的本地或云端模型

### Q: 如何获取 API Key？

你需要在对应模型服务商的官网注册账号并申请 API Key。例如：

- OpenAI：[platform.openai.com](https://platform.openai.com)
- DeepSeek：[platform.deepseek.com](https://platform.deepseek.com)
- 智谱 AI：[open.bigmodel.cn](https://open.bigmodel.cn)

### Q: 使用本地模型可以吗？

可以。只要你的本地模型服务提供 OpenAI 兼容的 API 接口（如 Ollama、LM Studio、vLLM 等），就可以在模型配置中填入对应的 Base URL 和 API Key。

### Q: 如何测试模型配置是否正确？

在模型配置页面填写好信息后，可以使用「测试连接」功能（如有），或者直接尝试生成一小段文字来验证配置是否正确。

## 小说创作

### Q: 推荐的写作流程是什么？

建议遵循以下流程：

1. 新建小说项目，输入故事灵感与基础设定
2. 生成全书大纲，必要时续写大纲完善细节
3. 拆分卷与章节
4. 进入章节，补充本章大纲
5. 生成正文初稿
6. 使用 AI 润色、钩子、质检等工具反复打磨
7. 确认后点击定稿（自动更新摘要、角色履历等）
8. 继续写下一章

### Q: 角色管理有什么用？

角色管理模块可以：
- 记录小说中重要角色的信息
- 从正文中自动提取关键人物
- 记录角色在各章节中的经历与变化
- 帮助维持人物一致性，避免人设崩塌

### Q: 章节摘要是什么？

每章定稿后会自动生成章节摘要。这些摘要会作为后续章节创作的上下文参考，让 AI 了解前文发生了什么，避免前后文矛盾。

### Q: 钩子与爽点辅助是什么？

专为网文连载场景设计的功能，可以帮助你：
- 在章节末尾制造悬念和断章点
- 设计让读者想继续追更的情节
- 提升章节的追读率

## 自媒体写作

### Q: 自媒体写作支持哪些类型？

支持多种自媒体内容类型，包括但不限于：
- 原创文章
- 模仿二创
- 选题灵感
- 各种平台风格（公众号、小红书、知乎等）

### Q: 可以指定写作风格吗？

可以。你可以设置语气风格、目标平台、目标字数等参数，AI 会根据你的设定生成相应风格的内容。

## 数据与安全

### Q: 我的小说数据会上传到云端吗？

不会。WritingStudio 是本地运行的桌面应用，所有小说项目数据都存储在你的本地设备上。仅在调用 AI 模型生成内容时，会将必要的文本内容发送给模型服务商。

### Q: API Key 安全吗？

API Key 存储在本地配置中，不会上传到任何第三方服务器。请妥善保管你的 API Key，不要将其提交到公开仓库。

### Q: 如何备份我的小说项目？

目前可以使用导出功能（如有）备份项目数据。更完善的备份与导出功能正在开发中。

### Q: 换电脑了如何迁移数据？

将 WritingStudio 的数据目录（通常在软件安装目录或用户目录下的对应文件夹）复制到新电脑的相同位置即可。

## 故障排除

### Q: 生成内容时卡住了怎么办？

可能的原因和解决方法：

1. **网络问题**：检查网络连接是否正常
2. **API 额度不足**：确认你的 API Key 还有可用额度
3. **模型响应慢**：大模型生成需要时间，请耐心等待
4. **内容过长**：尝试减少上下文长度或调整参数

如果问题持续，请在 Issue 中反馈。

### Q: 提示 API Key 无效？

请检查：
- API Key 是否复制完整，没有多余空格
- Base URL 是否正确（使用非 OpenAI 模型时需要设置）
- 模型名称是否正确
- 账户是否有可用额度

### Q: 生成的内容前后不连贯？

可以尝试以下方法：
- 确保前面的章节已点击「定稿」，生成了章节摘要
- 检查角色信息是否完整
- 在生成时使用「额外指令」补充上下文说明
- 适当调整上下文窗口设置

### Q: 软件闪退或无法启动？

请提供以下信息并在 Issue 中反馈：
- 操作系统版本
- 软件版本
- 闪退前的操作步骤
- 错误日志（如有）
