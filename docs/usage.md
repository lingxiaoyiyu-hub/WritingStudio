## 快速上手

### 安装与启动

1. 从 [Releases](https://github.com/lingxiaoyiyu-hub/WritingStudio-3.5.0/releases) 下载最新版本
2. 解压到本地任意文件夹
3. 双击运行程序

### 初始配置

首次启动后，建议先完成以下配置：

1. 进入**模型配置**页面
2. 填入你的 API Key
3. 设置模型名称和 Base URL（如使用非 OpenAI 模型）
4. 测试连接确保配置正确

## 模型配置

### OpenAI 模型配置

| 配置项 | 说明 | 示例 |
| :--- | :--- | :--- |
| API Key | OpenAI API 密钥 | `sk-xxxxxxxxxx` |
| Base URL | API 基础地址 | `https://api.openai.com/v1` |
| 模型名称 | 使用的模型 | `gpt-4o` |

| 配置项 | 说明 | 示例 |
| :--- | :--- | :--- |

### 智谱 AI 模型配置

| 配置项 | 说明 | 示例 |
| :--- | :--- | :--- |
| API Key | 智谱 API 密钥 | `xxxxxxxxxx.xxxxxx` |
| Base URL | API 基础地址 | `https://open.bigmodel.cn/api/paas/v4` |
| 模型名称 | 使用的模型 | `glm-4` |

### 本地模型配置

使用 Ollama、LM Studio 等本地模型服务时：

1. 确保本地模型服务已启动并监听端口
2. 在 Base URL 中填入本地服务地址（如 `http://localhost:11434/v1`）
3. API Key 可随意填写（本地服务通常不需要）
4. 模型名称填入你已下载的模型名称

## 小说创作

### 创建新项目

1. 在首页点击「新建小说项目」
2. 填写项目基本信息：
   - 项目名称
   - 小说类型/题材
   - 故事灵感/简介
   - 基础设定（世界观、背景等）
3. 点击创建

### 大纲推演

1. 进入项目后，点击「生成大纲」
2. 确认或调整故事灵感
3. 等待 AI 生成全书大纲
4. 如需要，点击「续写大纲」进一步扩展
5. 根据大纲拆分卷和章节

**使用技巧**：
- 灵感描述越详细，生成的大纲质量越高
- 可以多次生成，选择最满意的版本
- 大纲可以手动编辑调整

### 章节写作

1. 在左侧章节列表选择要写的章节
2. 补充或调整本章大纲
3. 点击「生成正文」
4. 根据需要使用「继续续写」扩展内容
5. 使用「额外指令」临时控制写作风格
6. 满意后点击「定稿」

**最佳实践**：
- 每章开始前先确认本章大纲清晰
- 善用上下文预览，确保前后衔接
- 初稿完成后再润色，不要边写边改
- 及时定稿，让后续章节有准确的上下文

### 角色管理

1. 进入「角色管理」页面
2. 手动添加角色，或从正文自动提取
3. 填写角色信息：
   - 姓名
   - 身份/职业
   - 性格特点
   - 外貌描述
   - 人物背景
4. 章节定稿后，角色履历会自动更新

### 润色与质检

**AI 润色**：
- 选择要润色的段落或全文
- 设置润色风格（如：更文学化、更口语化、增强画面感等）
- 点击润色，查看并应用结果

**钩子生成**：
- 在章节末尾使用钩子生成功能
- 选择钩子类型（悬念、反转、情感等）
- 生成多个钩子供选择

**质检查检**：
- AI 味检测：识别文本是否过于像 AI 生成
- 连续性检查：检查人物、线索、设定是否前后一致
- 断档检查：检查是否有遗留的未解决线索

## 自媒体写作

### 原创文章生成

1. 进入「自媒体写作」模块
2. 选择「原创文章」
3. 填写文章信息：
   - 文章类型
   - 内容领域
   - 目标字数
   - 语气风格
   - 目标平台
   - 主题/关键词
4. 点击生成

### 模仿二创

1. 选择「模仿二创」
2. 粘贴参考文章
3. 设置改写方向和风格
4. 生成新的版本

### 选题灵感

1. 选择「选题灵感」
2. 输入领域或方向关键词
3. 生成多个选题供参考
4. 可基于选中的选题继续生成文章

## 高级技巧

### 提升生成质量

1. **提供更详细的设定**：设定越丰富，生成的内容越贴合你的需求
2. **善用额外指令**：每章生成前添加临时指令，精准控制本章走向
3. **分段生成**：长章节分段生成，每段衔接更自然
4. **人工+AI 结合**：AI 生成初稿，人工打磨细节，效率最高

### 长篇创作建议

1. **规划先行**：先搭好全书骨架，再逐章填充
2. **及时定稿**：每章完成后及时定稿，更新上下文
3. **维护角色卡**：重要角色的信息要持续更新
4. **定期回顾**：每隔几章回顾一下摘要，确保整体连贯

### 常用提示词模板

**大纲生成**：
```
请帮我生成一个[类型]小说的全书大纲，故事背景是[背景设定]，主角是[主角信息]，核心冲突是[冲突描述]。
```

**章节正文**：
```
请根据本章大纲写正文，字数大约[字数]字，风格要求[风格描述]。注意承接上一章的情节：[上章摘要]。
```

**润色**：
```
请润色以下段落，让文字更有画面感，节奏更紧凑，同时保持原意不变。
```
